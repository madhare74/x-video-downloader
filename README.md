# Загрузчик видео X

Android-приложение: по ссылке на пост X (Twitter) находит видео и сохраняет MP4 на телефон
в выбранном качестве — по образцу ssstwitter.com. Для личного использования.

## Возможности (версия 1)
- Ссылка через «Поделиться» из приложения X, кнопку «Вставить» или подсказку из буфера обмена.
- Ссылки x.com / twitter.com (www., mobile., /i/status/, хвосты `?s=…`, `/video/1`) и короткие t.co.
- До 4 видео в посте, превью, длительность, список качеств MP4 (лучшее первым), размер файла.
- GIF скачиваются как MP4 без звука.
- Фоновое скачивание (WorkManager), прогресс в карточке и уведомлении, отмена, «Повторить».
- Сохранение в `Movies/X Downloader`, имя `X_<ник>_<id>_<номер>_<высота>p.mp4`, без перезаписи.
- История загрузок: открыть, поделиться, удалить; файлы, удалённые вне приложения, помечаются.
- Android 8.0+, Kotlin, Jetpack Compose, Material 3, светлая и тёмная тема.

## Откуда берутся данные
- Видео — напрямую с CDN X (`video.twimg.com`).
- Информация о посте — публичный сервис встраивания постов X (`cdn.syndication.twimg.com`),
  запасной способ — гостевой доступ сайта X (`api.x.com`, без входа в аккаунт).
- Оба способа неофициальные. Вся работа с ними — в `data/XSources.kt` и `data/XParsers.kt`.
  При непонятном ответе приложение показывает «X изменил формат данных, нужно обновление приложения».
- Закрытые аккаунты и контент с возрастным ограничением не поддерживаются.

## Сборка
GitHub Actions (`.github/workflows/android.yml`):
- `build` — unit-тесты и debug-APK; APK и результаты тестов публикуются в ветку `apk`,
  лог при ошибке — в `ci-logs-build`;
- `ui-tests` — UI-тесты на эмуляторе Android 11 и скриншоты экранов (ветка `ui-test-results`).

Автотесты используют сохранённые образцы ответов X (`app/src/sharedTest/fixtures`) и подставной
сервер, к X не обращаются.
